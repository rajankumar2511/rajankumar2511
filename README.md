Concurrency-safe doctor appointment platform built with **serializable PostgreSQL transactions, Redis idempotency, distributed locking, and CQRS + Transactional Outbox**.

`Node.js` `Express.js` `PostgreSQL` `Prisma` `Redis` `React` `Tailwind CSS` `BullMQ`

**GitHub:** https://github.com/rajankumar2511/Med
**Live:** https://med-kappa-five.vercel.app/

<details>
<summary><b>Architecture & highlights</b></summary>

* Serializable PostgreSQL transactions for race-condition-safe booking
* Redis idempotency and distributed locking
* CQRS + Transactional Outbox event pipeline
* BullMQ-powered notifications with a PostgreSQL-backed DLQ
* Reduced API latency **79ms → 47ms (40%)**
* Increased throughput **1,124 → 2,095 req/sec (86%)** under 100 concurrent users
* HMAC-verified payment workflow
* LLM-assisted symptom triage for intelligent doctor discovery
