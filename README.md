## 📌 Featured Projects

### [Daemon](https://github.com/rajankumar2511/Daemon) · Node.js, Express, Socket.IO, Redis, MongoDB, BullMQ, WebRTC
A scalable real-time messaging platform built on an event-driven Socket.IO architecture with Redis Pub/Sub, supporting 5,000 concurrent authenticated WebSocket connections in local load testing.
- Distributed presence system with online/offline status, last-seen tracking, and full message lifecycle (Sent → Delivered → Seen)
- BullMQ-based background workers with retry policies, exponential backoff, and dead-letter handling
- Peer-to-peer audio/video calling via WebRTC with Socket.IO signaling and Cloudinary media sharing
- Processed 100k+ events at 107k events/sec during local throughput benchmarking

**[Live Demo](https://daemon-frontend-one.vercel.app/)**

### [MediSlot](https://github.com/rajankumar2511/Med) · Node.js, Express, PostgreSQL, Prisma, Redis, React, Tailwind, BullMQ
A full-stack doctor appointment platform with secure booking, online payments, and AI-assisted doctor discovery.
- Concurrency-safe booking using serializable PostgreSQL transactions, Redis idempotency, and distributed locking
- CQRS + Transactional Outbox pattern powering an event-driven notification pipeline with a Postgres-backed DLQ
- Cut API latency from 79ms → 47ms (40%) and raised throughput from 1,124 → 2,095 req/sec (86%) under 100 concurrent users
- HMAC-verified payment workflow with atomic status updates in a single serializable transaction

**[Live Demo](https://med-kappa-five.vercel.app/)**
